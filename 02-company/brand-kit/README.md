# Brand Kit

Drop your brand assets here:

- **Logos** — all variations (full color, white, black, icon-only)
- **Colors** — hex codes, or a swatch image
- **Fonts** — font files or font names
- **Guidelines** — any brand or style guide PDF you already have

Then note the key rules under **Brand Kit** in `../CONTEXT.md` (primary color,
which logo to use where, fonts for headings vs body). Claude uses this when
producing anything visual or branded.
